# 💌 Drag Love Notes

An aesthetic interactive web experience featuring draggable paper-style love notes. Notes can be moved around the screen with smooth drag interactions, giving the page a playful handwritten-note feel.

Built with **HTML, CSS, and Vanilla JavaScript**, with support for both mouse and touch interactions.

## ✨ Features

- 📝 Interactive draggable paper notes
- 🖱️ Smooth mouse-based dragging on desktop
- 📱 Touch dragging support for mobile and tablets
- 🔄 Dynamic note rotation for a natural paper effect
- 📚 Dynamic `z-index` handling so the active note stays on top
- 🎨 Paper-style visual design with handwritten aesthetics
- ⚡ Lightweight — no frameworks or external JavaScript libraries required

## 🎮 How It Works

1. Open the webpage.
2. Select any paper note.
3. Drag it around the screen using your mouse or finger.
4. The selected note is brought to the front using dynamic layering.
5. Notes can be arranged freely to create your own layout.
